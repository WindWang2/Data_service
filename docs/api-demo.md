# 接口代码演示与资料管理

桌面程序包含“接口代码演示”和“资料管理”两部分。示例代码通过公开 `DataService` 工作；界面展示调用结果，不会执行任意粘贴的 C++ 代码。

## 准备工区

可通过“新建工区”建立空数据库，再导入自己的资料；也可先运行 `create_api_demo_project <新目录>` 生成明确标为合成数据的工区。仓库本身没有预置数据库或地震文件。

“打开工区”选择包含 `data.sqlite` 的目录。“导入目录”选择原始资料目录，两个目录不能混用。

## 从代码到结果

1. 选择示例和当前工区内的井、曲线、分层道、时深表或地震体。
2. 在导包/代码/返回类型页查看 CMake 依赖、头文件、完整调用和对象字段。
3. 填写深度、时间、道位置或测线号等参数。含义随示例变化。
4. 点击执行，查看图形和本次结果的 JSON 摘要。
5. 将导出的完整 C++ 源码编译为消费程序，链接安装后的 SDK。

界面会展示井清单、曲线、分层、时深、剖面、切片、地震文件信息、单道、INLINE/XLINE 和基础振幅处理等案例。返回摘要只适合检查结构与少量值；业务数据仍以方法返回的完整对象为准。

## 目录与实际数据

| 需要什么 | 调用 | 结果 |
|---|---|---|
| 工区中有哪些井 | `listWells` | `vector<WellSummary>` |
| 某井有哪些曲线 | `listData("curves", ...)` | `vector<DataEntry>` |
| 曲线的实际数值 | `readCurveSlice` | `CurveSlice` 的深度/数值/质量数组 |
| 一套分层的实际层段 | `readIntervals` | `vector<IntervalRecord>` |
| 时深配对点 | `readTimeDepth` | `TimeDepthTable` |
| 原生测线剖面 | `readSeismicLine` | `SeismicSectionResult` |

编号来自当前工区，不是数组下标。同名曲线可能属于不同来源或曲线组，应选定明确编号。井存在但曲线数为 0，可能表示该井只有坐标、分层或时深资料；先看来源状态和资料覆盖，不直接判定解析失败。

## 高清地震与剖面墙

地震剖面和切片默认勾选“原始分辨率”，不再默认使用稀疏网格。取消勾选后可按道数或每轴位置数限制读取快速预览。返回摘要会列出原始尺寸、返回尺寸和 `decimated`。

“剖面墙”示例支持直接输入多行有序 X,Y 坐标，并生成 `extractSection(SeismicSection, ...)` 的完整调用代码；请先核对地震体坐标和时间约定。结果工具栏可切换展开图和墙图、1:1 查看、缩放平移及导出。更多精度/内存说明见 [高清地震指南](hd-seismic.md)。

## 资料管理

导入后查看“来源清单”和“待核对”。`parsed` 表示对应范围已结构化，`review` 表示需核对，`registered` 表示仅登记，`failed` 表示失败，`ignored` 表示明确忽略。这些状态不是同一种成功。

曲线可按范围查看、清理或修改单点；原始值保留。分层可增删改。纠正井名或字段映射需要明确重新导入，填写核对结论不会自动更改数值。存在阻断问题时，原有效批次保持有效。

对于照片、地图和外部地震体，路径应始终可访问。文件移动后使用“重新定位来源”，不能只修改显示名称来替换文件。

更多完整程序见 [十个 C++ 案例](../examples/getting_started/README.md)，大目录导入设置见 [导入加速说明](import-performance.md)。
