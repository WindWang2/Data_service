# 便携运行与测试

本仓库是源码仓库，不包含已编译程序或任何预置数据。先按 [README](../README.md) 编译，再使用项目打包脚本部署运行依赖。打包工具参数以脚本的 `param` 定义为准。

Windows 运行目录需要应用程序、Qt DLL、`platforms`/`sqldrivers` 插件以及使用到的 FreeXL/libiconv 运行库。应移动完整运行目录，不能只复制一个 EXE。运行时无需编译器，但开发新 SDK 消费程序仍需匹配的工具链与依赖。

在 MSVC x64 开发终端中，以下命令示意将已构建程序打包到 `dist/PaleoDataService-Windows-x64`。路径换为自己的安装目录；依赖根目录应包含对应的 `include`、`lib` 和 `bin`。

```powershell
.\package-portable.ps1 -BuildDirectory .\build -QtRoot "C:/Qt/6.x/msvc2022_64" -DependencyRoot "C:/deps/runtime"
```

若工具不在当前环境中，可指定 `-CompilerSetup`、`-CMake`、`-Dumpbin`；额外运行库搜索目录通过 `-RuntimeDirectories` 提供。程序和示例的构建输出须匹配同一个 SDK 版本。已有同名打包目录时使用新的 `-PackageName`，脚本不会覆盖该目录。

## 合成演示

`create_api_demo_project <新的工区目录>` 在指定目录生成数学合成输入和数据库。生成器不会覆盖已有数据库，生成结果不用于真实地质解释，也不提交到仓库。

界面选择该工区后，可以检查井清单、GR/SP 曲线、分层、剖面和切片。若搬移了合成工区，应更新外部来源路径，或直接在新位置重新生成。

## 回归检查

```text
ctest --test-dir build --output-on-failure
```

使用多配置构建器时添加 `-C Release`。GUI 测试在无显示环境中可设置 `QT_QPA_PLATFORM=offscreen`；Windows 如需正确绘制文字，应提供可访问的字体目录。当前 CMake 定义包含解析、事务/重开/编辑、线程一致性、来源校验、地震读取与处理、界面契约等测试目标。

发布运行包前，在新的空目录中解压或复制完整包，隔离开发机路径后运行随包的自检入口。测试输出、临时工区、日志和截图只保存在本地，不纳入源码提交。

## 使用外部资料

1. 在仓库外建立自己的工区。
2. 导入目录时先用“引用原文件”，确认文件状态和待核对项。
3. 对照自有资料检查曲线数量、样点、分层、坐标及时间约定。
4. 对大地震体先读取文件信息和少量单道，再请求有界剖面或切片。
5. 关闭重开，检查记录仍然可读取。

来源文件不会因读取而被改写。数据库备份不自动包含外部文件；搬移工区需要同时保留或重新定位这些来源。不要把导入结果、真实截图或带数据路径的日志提交到代码仓库。
